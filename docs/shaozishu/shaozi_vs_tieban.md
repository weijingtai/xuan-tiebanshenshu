\## 2. 地支取数（邵子=河图数，\*\*≠铁板太玄地支数\*\*）

> \*\*铁板差异2\*\*：铁板地支常用\*\*太玄数（子9、丑8…）\*\*；邵子固定用\*\*河图生成数（1/6、2/7…）\*\*。



\## 3. 天地数定义（邵子核心，铁板无此严格区分）

\- \*\*天数 = 八字所有奇数之和（1、3、5、7、9）\*\*

\- \*\*地数 = 八字所有偶数之和（2、4、6、8、10）\*\*

\- \*\*天数基数=25，地数基数=30\*\*



\## 4. 完整算法步骤（可直接写代码）

输入：八字（年、月、日、时 → 4干4支）

1\. \*\*天干转邵子数\*\*：按上表，4干 → 4个数

2\. \*\*地支转邵子数\*\*：每支取\*\*2个\*\*（如子=1、6），4支 → 8个数

3\. \*\*合并所有数\*\*：4+8=12个数

4\. \*\*分天数/地数\*\*：

&#x20;  - 天数 = sum(所有奇数)

&#x20;  - 地数 = sum(所有偶数)

5\. \*\*取天地余数（关键）\*\*：

&#x20;  - 天余数 = 天数 % 25 （=天数>25则减25，取个位）

&#x20;  - 地余数 = 地数 % 30 （=地数>30则减30，取个位）

6\. \*\*寄宫修正（三元九运）\*\*：

&#x20;  - 上元（1864–1923）：男寄艮，女寄坤

&#x20;  - 中元（1924–1983）：阳男阴女寄艮，阴男阳女寄坤

&#x20;  - 下元（1984–2043）：男寄艮，女寄坤

7\. \*\*生成本命基数\*\*：

&#x20;  - 本命数 = (天余数 × 8) + 地余数 （范围：0\~249 → 映射6144条）



\*\*输出\*\*：本命数（0–249）→ 乘24 → 条文号（1\~6144）



> \*\*铁板差异3（最大）\*\*：

> - 铁板：用\*\*太玄数+考时定刻（精确到刻分）+八卦加则\*\*，无天地数25/30、无三元寄宫。

> - 邵子：\*\*无考时定刻\*\*，纯用八字干支河图数+天地数+三元寄宫。

\## 2. 卦数算法（八字转卦）

1\. \*\*用河洛天地数法算出天余数、地余数\*\*

2\. \*\*天余数→上卦，地余数→下卦\*\*

&#x20;  - 上卦 = 天余数 % 8

&#x20;  - 下卦 = 地余数 % 8

3\. \*\*卦数 = (上卦-1)×8 + 下卦\*\*（1\~64）



\## 3. 气数算法（邵子独有，铁板气数来自考刻）

气数 = \*\*元会运世数 + 节气数 + 命宫数\*\*

\- 元会运世：出生年份代入《皇极经世》元会运世表（1元=12会=360运=4320世）

\- 节气数：出生节气（如立春=1、雨水=2…）

\- 命宫数：河洛命宫（年干+月支）% 10



\*\*命数 = 卦数 × 气数 % 6144\*\*



> \*\*铁板差异5\*\*：

> - 铁板气数 = \*\*考时定刻（刻分）+太玄数\*\*

> - 邵子气数 = \*\*皇极元会运世+节气+命宫\*\*，无考刻
